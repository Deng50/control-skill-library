# 从原对象推导 MPC 的决策记录

## 1. 先确定当前调用的物理过程

读取入口、参数作用域、信号连接和采样时钟。对写作 y=Ax+Bu 的材料先给 y 定义。如果它是输出，这是输出映射，需要另找动态状态；若左侧是 ẋ，用连续方程；若为 x⁺，用离散转移，直接写明 Ts。仅凭矩阵字母无法判定。对 Python 逐层追踪初始化、step、积分器、延迟缓存、执行器与读出。对 Simulink 按 Inport → 运算/状态块 → Outport 顺信号查，记录状态及初值、每个时基、速率转换、Mask 或 workspace 参数、直接馈通/代数环和非连续逻辑。先对一个阶跃核实响应生效在哪个采样点，再冻结信号字典。

原辨识 SLX 内 Add1 汇入 b·u、c·q、a·v、f₀，Integrator 输出速度并进入 Integrator1，后者输出位置。于是 x=[q,v]，ẋ=[v,cq+av+bu+f₀]，y=[1,0]x。该例文件里的 C_continuous 在 MPC_QP 内乘 Ts 后参与扰动预测，符号 C 的物理用途应从调用和乘法核对。归档热 NMPC 有三个记录状态和四个热流记忆量，不能仅用温度与 SOC 完成相同条件下的马尔可夫递推。[移植逐点证据](../cases/plant-transfer/README.md) · [原生 MPC](../cases/native-mpc/README.md)

## 2. 选择能被验证的预测表达

连续线性系统和零阶保持用增广矩阵指数同时得到 A_d、B_d、E_d 和偏置。复现历史固定步长仿真时另核实其求解器离散轨迹；精确 ZOH 与固定步数值积分有可测差异。整数延迟增广输入 FIFO，每步先按旧缓冲驱动再更新。纯延时与一阶惯性分别改变响应起点与形状。非整数延迟、多速率或重采样需要说明相位与插值。局部线性化以实际工作点，检查单侧导数、半步长和原对象邻域误差；越过查表节点或逻辑开关时改用分段或保留原非线性转移。模型偏置和可测扰动预览均应进入自由响应。用固定输入序列、非零第二增量和逐列独立激励对照逐步递推，再决定是否开始整定。[矩阵核验](../cases/prediction/README.md) · [热对象局部矩阵](../cases/linearization/README.md)

## 3. 从目标到求解器配置

先记录跟踪信号和参考的时间索引、允许误差、执行器范围及可接受的变化速度。选 Ts 同时考虑最快目标动态、原模型的离散时钟和可用求解时间。用冻结阶跃比较原周期与候选周期，报告相位和超调变化；N·Ts 至少应让控制动作的影响到达输出，延迟大时短时域会看不到收益。M≤N，短控制时域之后选择保持末值或零增量并落实到矩阵。用物理容许偏差缩放跟踪、动作和 Δu，再调相对权重。硬约束直接限制 u、状态和定义清楚的 y；单位为每秒的速率界映射到每步应乘 Ts。对允许暂时越界的性能指标才引入非负 slack，同时记录罚权和实际 slack。饱和后的上一实际动作进入下一步。

线性预测、凸二次代价与线性约束构成 QP。检查 H 对称性、自由方向及正定/半正定要求、维数和求解器返回状态；有约束时用后验残差复算。非线性模型和非线性代价可用 NLP，标明初始猜测、容差和迭代上限。移位上次最优序列可作暖启动，多次复位试验须清空状态。在线超时、不可行和数值错误要分开记录；候选代码可报错终止仿真，设备回退动作需要专门验证。积分风up、执行器拒绝和超时不能靠裁剪输出掩盖。

## 4. 将算法放进正确的执行位置

| 现场载体 | 先核什么 | 控制器入口应交付什么 |
|---|---|---|
| Python 控制类 | reset 是否清除状态；每次 solve 接收的是测量还是下一步预测 | 模型与求解器只建一次，每拍更新参数和初值，返回第一步命令、解状态与耗时 |
| MATLAB 脚本/函数 | 文件解析路径、workspace、状态初始化、矩阵与求解器可用性 | 参数结构、可单测的 step、求解报告、冻结工况调用脚本 |
| MATLAB Function 块 | 编译后实际端口宽度、采样继承、固定尺寸、所用求解器的仿真/代码生成支持 | 函数体、连接位置、复位和 persistent 更新时机，目标代码另编译复核 |
| MPC Toolbox 块 | MV/MD/UD 分组、状态估计、单位、控制时域、外部 MV 接回端口 | 对象与配置、初始化脚本和块级闭环。只有实际验证才登记为已交付 |
| 显式 S-function | 初始化、Outputs、Update、DirectFeedthrough 和 SampleTimes | 每拍读/写状态的回调，测同一拍多次 Outputs 不会重复更新；注意 Stateflow 内部包装块 |

原二阶整定脚本的 fmincon 运行在闭环之外，调整 Q2、R；查看每拍代码才能确定在线算法。脚本设 0.01 s 而外评分固定乘 0.1，计算误差积分必须从每条日志的真实时间轴，对齐 r/y/u，保留绝对单位。固定采样等比乘法对特定工况排序可能不变，评分绝对值仍有误。独立测试需列出跟踪、控制总变化、硬约束余量和最慢/分位求解时间。按其他案例迁移时，先做权重扰动试验，验证修改的变量确实到达当前运行的模型。[原生实现与复验](../cases/native-mpc/README.md) · [约束权重调优](../cases/spring/README.md)
