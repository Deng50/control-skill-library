# 从信号日志到可以递推的神经模型

## 1. 先写预测请求，决定样本的一行代表什么

| 使用者交给模型什么 | 一行输入 → 标签 | 怎样验证承诺 |
|---|---|---|
| 初值、固定加热功率、一组查询时刻 | (t,T₀,P) → T(t) | 保留未见 (T₀,P) 组合，并独立核验热平衡和 t=0 |
| 每个控制周期的新动作，状态可重置或估计 | (x[k],u[k],d[k],局部时长) → x[k+1] | 切换输入、跨多个采样步连续递推，下一步使用上次预测 |
| 只有传感器输出与实际执行输入 | 本轨 y、u 的因果历史窗口 → y[k+1] | 用训练轨迹估窗口，在不同初态上评估启动与稳态误差 |
| 可调用名义转移，但一步有系统偏差 | (x,u,d) → x⁺_实测 − f_nom(x,u,d) | 同时保存 f_nom 版本和残差尺度，比较名义、修正两条自由递推 |

课题组二阶模型的真实因果链是 u → 加速度 → 速度 → 位移。存档 Data_collect 的三列只有时间、输入、位移。将输出差分当作速度时写清差分方向、单位、噪声和第一个窗口的处理；不能用未来一行位移初始化线上状态。有速度传感器或已验证观测器时优先验证其误差。仿真记录到的内部真值可以做评分。真实状态递推从接受的估计初态开始。[对象原件版本](../sources.json) · [原生速度记录](../cases/plant-transfer/README.md)

## 2. 先证明采数器与时间轴可用

取模型声明的零输入和一个正阶跃。检查初值、首个响应点、方向、稳态值和输入结束后的自由衰减。本例 f₀=1，零输入平衡位置为 1/9，在零位移初态会自行运动。若轨迹从零开始就平直，先查偏置项。训练状态切换不要跨复位边界。阶跃揭示响应和偏置，多次切换揭示记忆，幅值和频率覆盖预期操作区。积分器不能仅依靠常值稳态点辨识；记录哪些方向仍缺激励。独立选择验证、测试的整条工况。同一解析条件的重复采样共享分区。保存未缩放的原表和变换定义，换列名需有信号映射；相同的列名也可能分别代表命令和执行值。[数据窗程序](../controlkit/table.py) · [源二阶回放](../cases/matlab/README.md)

## 3. 从有单位的方程构造损失

以时间缩放 z=(t−t₀)/s_t，输出 y=μ_y+s_y·net(z,ξ) 为例，dy/dt=(s_y/s_t)∂net/∂z。二阶导数有 s_y/s_t²。s_t 应与方程的物理时间单位一致。多状态网络逐分量求导；调用 autograd 前启用时间梯度，在计算物理项的训练路径保留求导图。归一化输入上的导数直接与物理量相加会改变 C、阻尼或惯量的等效数值。恒功率热例以 W 检查 C·dT/dt+G(T−Ta)−P；轨迹初值项以 K 检查。对分段保持控制，在单个保持区间内取方程配点，切换瞬间检验状态连续，并允许导数改变。初始条件由已知复位值或测量不确定度决定，禁止从测试序列未来值反推。

先写一个解析轨迹或对可信积分器做局部差分，用原单位容差验残差，再依训练集量纲或测量不确定度归一化各项。检查数据、初值、物理损失及对参数的单独梯度；相对权重应由验证工况选定。物理式缺参数时，报告缺的是常数、输入还是状态。若要联合辨识，须用激励/灵敏度检验可辨识性；否则运行纯数据分支。用物理模拟数据训练得到的普通监督网络应按实际目标函数标记。[恒功率实现](../controlkit/thermal.py) · [二阶神经模型](../cases/object-plant/README.md)

## 4. 让网络选择接受反证

优先用保持值、线性动态或机理模型确定基线。可观测 Markov 状态用小 MLP 开始；存在输入延迟时显式追加动作历史，比任意加深网络更容易验证。仅在同一条因果历史不能解释长期状态且数据覆盖充分时评估时序模型。需要二阶导数时选有平滑二阶导数的激活。先用一个短工况排查单位和梯度，再在训练工况内比较层宽、学习率、配点及损失权重。模型、数据、种子、优化步数和验证选择规则绑定保存。对同一批输入重载验证；任何单位或特征顺序改动都要在接口边界显式转换。

| 症状 | 可区分原因的实验 | 下一步 |
|---|---|---|
| 单步误差小，多步很快漂移 | 对同一序列同时记录教师强制与自由递推，查看第一处分歧 | 检查偏置、隐藏状态、初态、对时，再评估多步损失 |
| 物理损失很小，幅值和初值却错 | 比较独立初值误差和能满足方程的平凡解 | 增加可辨识条件、校准数据项和初值项 |
| 拟合误差小，反传物理项不更新 | 对一个时间点、一个参数分别做双边差分 | 检查断图、没乘时间尺度、求错通道 |
| 测试异常好 | 交换列序、克隆条件换轨迹号、打乱分区 | 检查列映射、工况泄漏及缩放拟合范围 |
