# 从对象接口到闭环 MPC

在工作点附近可写 x⁺=Ax+Bu+Ed+b，y=Cx+Du。增量坐标用 δx、δu，保留平衡点；绝对坐标下非零偏置 b 不能直接丢弃。取样约定决定直接通道 D 乘哪一步的输入。本库矩阵核验采用 y[k+1]=Cx[k+1]+Du[k]。对给定 Δu，先下三角累加得到绝对 u，同时带入上一实际 u。块 Toeplitz 映射每一列影响本步及以后所有受影响的输出。用不同列的基向量和组合增量检验。[三步反例](../cases/prediction/README.md)

连续对象在零阶保持假设下对增广 [A B E] 作矩阵指数，一并离散控制和扰动。数值线性化用左右单侧、步长减半、非线性原模型邻域探针；在规则切换处左右导数不一致时缩小工作域、切换到分段或非线性预测。在域外重新验证。只有已知状态及扰动可用时才能直接送控制器。[热管理案例](../cases/linearization/README.md)

弹簧例优化 Σ(q(e/1 m)²+r(u/4 N)²+s(Δu/4 N)²)，输出与位置约束相同。达到控制步数后持末值。硬位移、速度、力边界进入求解器；Δu 仅作平滑代价。若业务另有硬速率限制，需要在决策变量上增加差分不等式并按 N/s 与 Ts 换算。时域覆盖 N·Ts 秒，依据对象响应与计算预算选择。本例求解失败显式报错、标记该候选不可用。现场备用控制律须结合对象另验。外评分冻结为 RMSE/1 m + 0.002·RMS力/4 N + 0.0001·总动作变化/4 N，先排除越界；固定工况长度后比较总变化。比较均值、P95、约束和跟踪时请保留每条轨迹。[闭环及配置](../cases/spring/README.md)
