# 阀门流量 MPC

部署时调用 `solution.plan(x, r, d, last, cfg)`。将所选候选字典的 `q`、`r_u`、`s` 合入公共配置；每次传入 N 个参考和扰动预览值。返回长度为 N 的命令 `u`、传感器预测 `y`、完整预测成本 `J` 以及 `status` 和 `message`。仅下发首个命令，下一拍传入最新测量和上一实际下发命令。

## 采样与预测

令流量状态为 f，实际阀位为 a，采样间隔为 h=dt，阀位保持系数为 ρ=exp(−h/0.75)。每个预览样本与同拍调用原过程得到的传感器值配对。

    f[k+1] = (1 − 0.8h) f[k] + h(1.1 a[k] + 0.3 d[k] + 0.09)
    a[k+1] = ρ a[k] + (1 − ρ) u[k]
    y[k]   = f[k+1] + 0.12 a[k] + 0.05 u[k]

当前命令经 0.05 直接影响本拍输出，也经阀位惯性影响后续流量。预测程序分别递推零命令自由响应与各个命令的输出系数，从而包含初态、扰动、偏置和直接通道。程序在输出计算后推进阀位。

## 约束与失败处理

决策变量是前 M 个绝对命令。余下 N−M 拍重复第 M 个命令。优化在整个 N 拍内累计 q(y−r)² + r_u u² + s(Δu)²，其中第一项命令差为 u[0]−last。幅值界是 [lo, hi]，相邻命令差界为 ±rate·dt。第一个命令还受 [last−rate·dt, last+rate·dt] 约束。

将传感器预测代入成本即得凸二次规划。SLSQP 使用解析梯度、按共同正数缩放的目标函数和可行初值。成功后复查硬界并消除浮点舍入残差，使用最终命令重新计算输出与成本。若速率为零、界限重合或目标恒定，直接返回可行保持解。

第一个命令的可达区间为空时抛出包含 `Infeasible first command` 的 ValueError。数值求解报告失败或候选违反约束时，从可达区间取最接近 last 的命令并保持，状态为 `fallback_hold`，消息保留求解器返回说明。设计和验证遇到回退会报错中止，部署方可按状态处理。

## 设计与验证

每拍按 t=(k+arange(N))·dt 获取实际工况的参考和可测扰动预览，基线使用当前参考。两者使用相同的原过程、各工况初值、上一命令和 40 拍长度。外部指标为传感器跟踪 RMSE + 0.015·RMS(u) + 0.03·RMS(Δu)。计算 Δu 时计入工况给定的上一命令。

三组权重按编号 0、1、2 的设计指标分别为 0.175454、0.173251、0.179748。选择编号 **1**（q=2，r_u=0.015，s=0.02）。

| 验证工况 | 跟踪 RMSE | RMS(u) | RMS(Δu) | 外部指标 |
|---|---:|---:|---:|---:|
| 现场基线 | 0.292224 | 0.365062 | 0.109906 | 0.300998 |
| MPC | 0.150015 | 0.429833 | 0.121072 | 0.160095 |

MPC 的验证指标降低 46.8%，同时命令幅值和变化量的均方根有所增加。验证最大单拍命令变化为 0.21，等于该工况的速率上限。CSV 保存 MPC 实际下发命令及同拍原过程输出。

在本目录运行 `python solution.py` 生成结果，运行 `python self_check.py` 独立复核。35 组计划的最大输出递推误差为 4.44×10⁻¹⁶，使用原对象逐列激励和线性规划得到的最大内部成本次优上界为 3.54×10⁻⁶。自检还覆盖失败分支、不可行初始命令，以及全部 40 行实际验证轨迹。
