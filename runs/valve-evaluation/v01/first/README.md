# 阀门流量 MPC

在本目录运行 `python solution.py` 可重新生成 `summary.json` 和 `validation.csv`。部署时调用 `solution.plan(x, r, d, last, cfg)`，将所选候选的三个权重合入 `cfg`，每拍执行返回序列的首项。

## 采样顺序与代价

记流量偏差为 f，实际阀位为 a，采样周期为 h，阀门保持系数为 ρ = exp(−h/0.75)。给定当拍的扰动 d 与命令 u，预测依次使用以下关系。

```text
f_next = f + h * (−0.8*f + 1.1*a + 0.3*d + 0.09)
a_next = ρ*a + (1−ρ)*u
y      = f_next + 0.12*a + 0.05*u
```

传感器叠加了更新前的阀位和当拍命令。输出 y 与同一拍的参考值比较。对 N 拍累加 q·(y−r)² + r_u·u² + s·(u−previous)²，首拍的 previous 取上次实际执行的命令。每拍重建预览，仅优化前 M 个命令，后续重复第 M 个命令。

## 求解与失败处理

沿预测时域递推零输入响应与各独立命令的输出灵敏度，得到输出对命令的仿射函数。SciPy SLSQP 以解析梯度求解该凸二次规划。每个命令位于 [lo, hi]，相邻命令差的绝对值至多为 rate·h。首个命令同时满足幅值限制及相对于 last 的增量限制。

若这两个首拍区间无交集，部署接口抛出带有原因的 `ValueError`。若存在可行解但求解器失败或返回超限动作，接口将上一命令投影到首拍可行区间并保持，在 `success=False` 和 `status` 中报告原因，重新计算这组动作对应的 y 和 J。闭环摘要记录各控制器发生回退的时刻。固定命令或零变化率直接计算唯一可行序列。

## 设计与验证

外部指标为输出跟踪 RMSE + 0.015·RMS(u) + 0.03·RMS(Δu)。每个工况均使用给定初态、上次执行命令及精确预览。表中数据为闭环实测值。

| 工况 | 控制器 | 跟踪 RMSE | RMS(u) | RMS(Δu) | 外部指标 |
| --- | --- | ---: | ---: | ---: | ---: |
| 设计 | 基线 | 0.35134 | 0.37619 | 0.10718 | 0.36019 |
| 设计 | 候选 0 | 0.16599 | 0.44132 | 0.09496 | 0.17545 |
| 设计 | 候选 1 | 0.16273 | 0.46078 | 0.12020 | 0.17325 |
| 设计 | 候选 2 | 0.17081 | 0.42076 | 0.08748 | 0.17975 |
| 验证 | 基线 | 0.29222 | 0.36506 | 0.10991 | 0.30100 |
| 验证 | 候选 1 | 0.15002 | 0.42983 | 0.12107 | 0.16009 |

候选 1 在设计工况取得最小外部指标，权重为 q = 2、r_u = 0.015、s = 0.02。在独立验证工况，跟踪误差下降，命令及其增量的均方根有所增加。设计及验证仿真均未触发求解回退。
