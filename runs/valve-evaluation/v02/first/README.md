# 阀门流量预览 MPC

从本目录运行 `solution.py` 会按设计工况选取权重，并生成独立验证工况的 `validation.csv` 和 `summary.json`。运行 `self_test.py` 可复验预测、约束、最优性和已生成的轨迹。部署入口为 `solution.plan(x,r,d,last,cfg)`。每拍将返回值 `u[0]` 下发给原对象；下一拍传回更新后的状态与实际下发命令。

## 模型与时标

用 f、a、u、d 分别表示流量偏差、实际阀位、阀命令和可测扰动。采样周期为 h，阀惯性系数为 ρ = exp(−h/0.75)。在第 k 拍开始读取旧状态，预览数组的第 i 项对应时间 (k+i)h。

    f⁺ = (1 − 0.8h)f + 1.1h a + h(0.3d + 0.09)
    a⁺ = ρa + (1 − ρ)u
    y  = f⁺ + 0.12a + 0.05u

当拍命令通过传感器的 0.05u 项立即影响读出。阀惯性引起的流量变化从下一拍开始。每次用当拍 step 的读数 y 与当拍参考 r 比较。两个工况均按 settings.json 指定的解析预览生成全部 N 项，末几拍也照此取值。

## 优化与故障处理

优化变量是前 M 个绝对命令，从第 M 项起保持同一值。逐步传播状态对各命令的灵敏度得到输出增益矩阵，零命令递推得到含初态、扰动和常偏置的自由响应。三项二次代价按 N 拍相加。第一增量取 u[0]−last，其余增量逐拍差分。保持段的命令惩罚仍逐拍计入。

SciPy SLSQP 使用解析梯度求解凸二次规划，同时约束每个命令在 [lo,hi] 内、每次命令变化在 ±rate·h 内。初始化为距离 last 最近的界内常命令。程序先检查首拍幅值和速率区间是否相交。无交集时抛出 ValueError，求解失败或返回的解违反硬约束超过 1e−9 时抛出 RuntimeError。成功时返回状态 optimal、完整命令序列、逐拍读出和按原权重重算的 J。失败时调用方可捕获异常，启动现场定义的处置流程。

## 实测结果

按 RMSE(y−r) + 0.015 RMS(u) + 0.03 RMS(Δu) 选型。设计工况三组权重按 settings.json 顺序的得分为 0.175454、0.173251、0.179748。选择零起始编号 1，采用 q=2、r_u=0.015、s=0.02。验证从相同初态和上一命令开始，各运行 40 拍。

| 验证控制器 | 流量跟踪 RMSE | RMS(u) | RMS(Δu) | 外部得分 |
| --- | ---: | ---: | ---: | ---: |
| 现场基线 | 0.292224 | 0.365062 | 0.109906 | 0.300998 |
| 候选 1 | 0.150015 | 0.429833 | 0.121072 | 0.160095 |

在给定验证工况中，候选 1 的跟踪误差下降，命令幅值和变化量的均方根均有所增加。最大约束残差为 1.11×10⁻¹⁶。CSV 记录从原对象取得的实际 y 和已执行的首个命令。
