# 阀门流量 MPC

在本目录运行 `python solution.py` 可生成设计、验证两种工况的指标，以及验证工况逐拍实测的 CSV。部署时调用 `solution.plan(x, r, d, last, cfg)`，仅下发 `u[0]`。首次调用需要提供上一实际命令，后续每拍更新状态、上一实际命令与预览。运行需要 NumPy 和 SciPy。

## 每步预测

记流量为 f，实际阀位为 a，指令为 u，可测扰动为 d，采样间隔为 h。每步使用过程原始采样顺序。

```text
ρ       = exp(−h / 0.75)
f[k+1]  = (1 − 0.8h) f[k] + 1.1h a[k] + h (0.3 d[k] + 0.09)
a[k+1]  = ρ a[k] + (1 − ρ) u[k]
y[k]    = f[k+1] + 0.12 a[k] + 0.05 u[k]
```

预测的传感器值使用更新后的流量和本拍开始时的实际阀位。仿真中的时间 t=k·h 对应本次调用原始 step 返回的传感器值。

## 控制器与故障状态

求解变量为前 M 拍的绝对命令 v。控制序列取 u[k]=v[min(k,M−1)]。代码按上述递推生成偏置和增益矩阵，使整个输出预览满足 y=b+Gv。SLSQP 用解析梯度求解凸二次目标，累计全部 N 拍的 q(y−r)²、r_u·u² 和 s·(Δu)²。每拍命令限制在 [lo,hi]，相邻命令之差的绝对值至多为 rate·h，第一拍相对于 last 计算。

返回的 J 按最终命令及其预测输出重新计算。正常求解返回 `status="optimal"`。求解器报告失败或解超出允许的数值容差时，返回 `status="fallback"`，保留求解器消息，并将投影到命令幅值区间的 last 保持整个时域。若首拍幅值与速率区间无交集，抛出带原因的 ValueError，调用方需处理不可行状态。

## 设计与验证

每种权重从各工况给定初态独立启动，按实际输出跟踪误差和实际命令计算 RMSE(y−r) + 0.015 RMS(u) + 0.03 RMS(Δu)。三组权重在设计工况分别取得 0.175454、0.173251、0.179748，选择零起始编号 1，对应 q=2、r_u=0.015、s=0.02。

| 验证控制器 | 流量跟踪 RMSE | RMS(u) | RMS(Δu) | 综合指标 |
|---|---:|---:|---:|---:|
| 现场基线 | 0.292224 | 0.365062 | 0.109906 | 0.300998 |
| MPC | 0.150015 | 0.429833 | 0.121072 | 0.160095 |

验证工况的跟踪误差下降，命令幅值和变化量的均方根略有增加。设计和验证中的 MPC 均未触发回退。运行 `python selftest.py` 可重放验证数据，并独立检查变化时域下的约束、目标、最优性与故障状态。
