# 未见任务对照结果

在三个新接口和一个完整阀门 MPC 交付中，无库组与显式使用 Skill 组都在首次提交时通过。两项试验的成功率差均为 0 个百分点。本次证实的是两组在给定任务上的交付能力，样本不足以判定 Skill 在其他对象上的收益。真实素材案例的物理和闭环指标另有独立验收。[三项工程案例](../README.md) · [工程验收结果](../runs/field-acceptance.json)

## 三个跨角色子任务

每次新建无历史会话，一次接收同样的三题。每组 3 个会话，每个会话最多 6 分钟、12 次顶层工具调用，可自行写测试。题面、两份过程接口和隐藏评审器在本轮工程 Skill 改写前冻结。各组沿用相同模型设置和 Python 环境。参与者通过工作目录及访问指令隔离，未使用操作系统级访问控制。一次 CLI 启动故障发生在题面送达之前，未计入成绩。有效会话均使用相同启动方式。[协议](paired/protocol.md) · [冻结摘要](paired/frozen.json) · [原题](paired/brief.md)

| 首次隐藏验收 | 无库 | 库可自行查阅 | 每题显式调用 Skill |
|---|---:|---:|---:|
| 将分钟与 kW 的网络输出还原到物理方程，保留参数梯度，缺方程时走数据分支 | 3/3 | 3/3 | 3/3 |
| 从带记忆、直接通道的风门逐拍接口生成增量预测矩阵 | 3/3 | 3/3 | 3/3 |
| 按专家实际时序计算含执行器滞后与可微感知的 PGAC 代价 | 3/3 | 3/3 | 3/3 |
| 合计通过的子任务 / 实际提交 | **9/9** | **9/9** | **9/9** |
| 首次提交后三题都通过的独立会话 | 3/3 | 3/3 | 3/3 |
| 隐藏评分后返工 | 0 | 0 | 0 |

无库组为 r01、r04、r05。自由查阅组中 r02、r03 只查阅了知识条目，r06 实际打开了三个 Skill。观察到前两份查阅回执后、查看隐藏成绩之前，增加 s01–s03 显式调用组。该组 3/3 会话分别为三题打开了相应 Skill。分子是首次**对外提交**后通过的题数，允许提交前自主调试。每组 9 项观测来自 3 个重复题面的独立会话，题目难度和模型上限限制了区分度。[补充组协议](paired/activation.md) · [查阅回执、逐题首交结果与提交摘要](../runs/paired/results.json)

评分后另做故障注入，分别改变物理时间单位、缺方程分支、第二次增量传播、直接通道、感知耦合和 Actor 梯度。用参与者原样提交的自测命令执行，每个会话先通过正常代码，再单独注入每种错误。三组均检出 18/18 次。此结果衡量这些特定故障的自测覆盖。[故障注入程序](paired/test_reach.py) · [逐会话故障结果](../runs/paired/test-reach.json)

## 完整阀门 MPC 的独立迁移

从新的阀门惯性过程出发，交付求解器与失败处理、自主选择的权重、基线对照和 40 拍实际执行日志。每组 2 个全新会话，各限 9 分钟、18 次顶层调用。评分器用 3 组未提供的配置改变周期、上一动作和控制时域，复核可行域、预测、成本以及解与独立数值优化的目标值，再重算选型和验证日志。该题在工程库快照冻结后另行设计，题面与评审器在四个会话启动前固定。[原题](valve/brief.md) · [协议](valve/protocol.md) · [隐藏验收代码](valve/check.py)

| 首次交付 | 无库 v01、v04 | 显式调用 v02、v03 |
|---|---:|---:|
| 完整验收 | **2/2** | **2/2** |
| 隐藏评分后返工 | 0 | 0 |
| 验证工况综合指标，越低越好 | 约 0.160095 | 约 0.160095 |

四次独立交付均选中编号 1 的权重，给定现场基线在同一工况为 0.300998。两组都获得这个相对基线的控制性能改善。两次有库提交均记录了实际使用的 MPC 角色入口、预测核验和约束调参 Skill。该试验覆盖一个工程对象的重复交付，未测量对象建模与轻量化在完整新项目中的相对成功率。[逐次解、基线与 Skill 查阅记录](../runs/valve-evaluation/results.json)

## 复算

从库根运行以下命令，使用交付的首次源码、固定的库快照和隐藏检查器重新评分。此命令复算原提交的数值结果；新开智能体再解一次是独立的新实验。

```powershell
Set-Location D:\projects\control-skill-library
$py = 'D:\projects\control-agent-harness\.venv\Scripts\python.exe'
& $py replay.py benchmark
```

三题实验的首交代码与自测保存在 `runs/paired/<会话>/first`，完整控制器连同其 summary.json 和 validation.csv 保存在 `runs/valve-evaluation/<会话>/first`。例如可逐行检查无库 v04 与显式调用 v02 的交付。[v04 轨迹](../runs/valve-evaluation/v04/first/validation.csv) · [v02 轨迹](../runs/valve-evaluation/v02/first/validation.csv) · [试验用库快照](../runs/paired/library-snapshot.zip)
