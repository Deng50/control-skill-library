# 盲评协议

在工程 Skill 本轮改写前冻结 brief、两份现场接口和 judge。三个留出任务分别检查热残差的单位和可训练梯度、带记忆风门的预报矩阵、带实际执行器滞后的策略滚动代价与梯度。它们相对于案例为新对象或新接口，属于可机器验收的工程子任务。各组得到相同题面、两份接口文件和 Python 环境。评审器仅评审端可见。使用同模型、独立新上下文，不透露历史得分。无库组仅访问本工作目录；有库组额外获得本轮库副本。所有选手可在提交前运行自测；首次提交后单独评分。不得将失败归入另一项或将没有响应混为算法失败。目标为每组至少两次独立会话，每会话各解三题。交错分配顺序。记录首次成功的分子/分母、每题明细、实际查阅、返工、修复后成绩、资源条件和隔离方式。本实验仅测三库共同可用的效果；解释结论时需考虑重复题目及样本量。
